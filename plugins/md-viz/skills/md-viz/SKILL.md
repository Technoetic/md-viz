# ⚡ 마크다운 풀스택 고자극 시각화 (`md-viz` Overdrive)

호출 뒤에 적힌 파일 경로 또는 제공된 본문을 대상으로 한다. 게시 위치나 원하는 도구·톤을 명시적으로 지정하면 따른다. 대상이 생략됐으면 현재 대화에서 명확하게 가리키는 문서를 사용하고, 후보가 여럿이면 어느 파일인지 한 번만 묻는다.

> **기본 설계 철학 (Full-Arsenal High-Impact Overdrive):**
> 밋밋한 회색 도식 한 장으로 끝내지 않는다. 기본 호출은 **가용한 모든 시각화 라이브러리(최대 25종)와 모든 GitHub Markdown 연출 기법(핵심 6종 + 네이티브 부스터 4종)을 총동원**해, 독자가 문서를 여는 순간 시선을 사로잡고 구조·수치·흐름·시간·공간·수식·코드를 다각도에서 즉각 체감하게 만드는 **극단적 고대비·고자극 쇼케이스 시각화**를 기본 목표로 삼는다.
> *(단, 사용자가 `"그림 한 장만"`, `"Mermaid만"`, `"차분하게"`처럼 범위를 좁히면 그 지시를 최우선한다.)*

## 0단계 · 실행 전 로컬 엔진 전수 탐지 (`check_env.py`)

작업을 시작하면 먼저 번들 스크립트 [로컬 렌더러 탐지기](scripts/check_env.py)를 실행해 현재 머신에서 바로 돌릴 수 있는 엔진을 파악한다.

```sh
python scripts/check_env.py --json
```

- `ready`로 감지된 엔진은 **망설이지 말고 모두 실렌더링**한다.
- `runtime-only`(Node/R/Python 실행기는 있으나 패키지가 다른 경로에 있는 경우)는 프로젝트 `node_modules`·가상환경·브라우저 캡처 경로를 확인해 가능한 한 실출력을 확보한다.
- 끝내 로컬에 설치되지 않은 엔진은 **대체 렌더러 또는 라이브 GitHub 네이티브 문법(`mermaid`, `geojson`, `$$...$$`)** 으로 우회하고, 최종 집계에서 **실제 출력한 도구**로만 정직하게 기록한다.

## 1단계 · 25종 라이브러리 최대 커버리지 전개 규칙

1. **다각도 분해(Multi-Lens Expansion):** 같은 문서·같은 데이터라도 독자가 던지는 질문이 다르면 **서로 다른 전용 라이브러리로 겹치지 않는 시각 렌즈를 끝까지 전개**한다.
   - 흐름·상태·분기·일정 → **Mermaid** (라이브 네온 `classDef` 코드 블록 + 필요 시 정적 고해상도 카드)
   - 행위자 간 시퀀스·프로토콜 → **PlantUML**
   - 의존 그래프·자동 레이아웃 → **Graphviz**
   - 계층·컨테이너·인프라 그룹 → **D2**
   - C4 아키텍처 경계·외부 시스템 → **Structurizr**
   - 목차·개념 계층 방사형 분기 → **markmap**
   - 공간 배치·평면도·개념 스케치 → **Excalidraw**
   - 타이밍·클록·상태 전이 파형 → **WaveDrom**
   - 박자·멜로디·리듬·신호 악보 → **abcjs**
   - 시계열·누적·다변량 비교 → **Vega-Lite** & **Altair**
   - 극좌표·정밀 공학 플롯 → **Matplotlib**
   - 상관·밀도·히트맵·분포 → **seaborn**
   - 그룹 분포·상자+산점도 → **ggplot2**
   - 구성비·도넛·간결 대시보드 → **Chart.js**
   - 순위·클리블랜드 도트·비교 → **Observable Plot**
   - 폭포(Waterfall)·증감 분해·확대형 → **Plotly**
   - 흐름량 생키(Sankey)·연동 차트 → **Apache ECharts**
   - 원형 시퀀서·방사형·커스텀 기하 → **D3**
   - 토폴로지·신호망·노드 이웃 탐색 → **Cytoscape.js**
   - 실제 경위도·경로·권역 지도 → **Leaflet** (+ GitHub 라이브 **GeoJSON**)
   - 정적 고대비 구문 강조 카드 → **Shiki**
   - 런타임/브라우저 강조 카드 → **highlight.js**
   - 정밀 TeX SVG 수식 카드 → **MathJax**
   - 초고속 빌드 수식 카드 → **KaTeX** (+ GitHub 라이브 **`$$...$$`**)
2. **최대 25종 실전 투입:** 원문에 단서가 있거나 다각도 해석이 성립하는 모든 항목에 **실제 출력을 생성해 문서에 전면 배치**한다. `25종` 모두 쓰임이 성립하면 기본 호출에서도 **25/25 전량 투입**한다. 결과가 많을 때는:
   - 핵심 하이라이트 `4~8`장은 본문 상단·핵심 절 바로 옆에 **대형 임팩트 카드**로 배치하고,
   - 나머지 전량은 본문 안의 **멀티컬럼 시각 갤러리 월(`<details open>` 3열/2열 이미지 매트릭스)** 에 직접 노출해 독자가 클릭 이동 없이도 한 화면에서 전 라이브러리의 화력을 즉각 체험하게 한다.
3. **고자극 비주얼 연출 규격 (Electric High-Contrast Visual Spec):**
   - **팔레트:** 깊은 옵시디언 다크 캔버스(`#0B0F1A` / `#131621`) 위에 고채도 네온 시그널(`#00F5D4` 시안 · `#FF2E93` 핫 마젠타 · `#C8FF00` 애시드 라임 · `#FF9E00` 솔라 앰버 · `#7B61FF` 울트라바이올렛 · `#FF3864` 크림슨 펄스)로 시선을 강렬하게 고정한다. 밋밋한 기본 회색·흐린 파스텔을 피한다.
   - **시각 리듬:** 정지 카드만 나열하지 않고 **`<picture>` 루프 애니메이션 GIF(`12~36`프레임, `prefers-reduced-motion` PNG 짝)**, **라이브 네온 Mermaid**, **라이브 GeoJSON 지도**, **라이브 `$$...$$` 수식**, **다중 줄 2톤 네온 SVG 배지 월**, **2×2·3×N 멀티컬럼 시각 비교표**를 교차 배치해 스크롤할 때마다 시각적 쾌감과 정보 밀도가 동시에 폭발하게 구성한다.
   - **가독성·직접 라벨:** 모든 핵심 피크·노드·구간에 값과 단위를 직접 라벨링하고, 배경색 대비(WCAG)를 확보하며, 모든 이미지에 내용이 드러나는 대체 텍스트(`alt`)와 짧은 핵심 해석 캡션을 붙인다.
4. **사실 정직성 철칙 (자극적 연출 ≠ 날조):**
   - 원문의 **수치·단위·날짜·방향·인과·출처·파일 경로는 단 하나도 왜곡하거나 지어내지 않는다.**
   - 값이 없는 비교는 정성적으로 표현하고, 계획·예상치는 실측치와 명확히 구분한다.
   - 25종 전체 시연이나 짧은 원고의 극대화 시연에서 특정 엔진을 보여 주기 위해 추가 입력을 구성해야 할 때는 반드시 **`시연용 예시` / `Illustrative Example`** 표식을 그림 캡션과 본문에 명시한다.
   - 기존 원고, 링크, 복사 가능한 코드 예제, 작성자 그림은 보존하며, 생성 파일에는 절·엔진이 드러나는 안정적인 이름을 써서 재실행 시 중복 없이 갱신한다.

**호출 범위 지정:** `'그림 한 장만'`, `'코드만'`, `'Mermaid만'`, `'차분하게'`처럼 사용자가 범위를 지정하면 그 범위가 우선한다. `'21종 전체 시연'`은 도식·차트 21종, `'25종 전체 시연'`은 코드·수식 포함 25종, `'Markdown 표현 6종 시연'`은 핵심 표현 6종, `'전부 시연'` 또는 기본 호출은 **25종 + 6종 + 네이티브 부스터 4종 전체**를 대상으로 한다.

## 2단계 · 이모지·네온 배지 월·알림 5종·네이티브 부스터 전면 배치

모든 기법의 복사 가능한 완성 문법은 [고자극 GitHub 표현 패턴집](references/markdown-patterns.md)을 따른다.

### 핵심 6종 GitHub Markdown 표현 (6/6 전면 투입)

| # | 표현 기법 | 극대화 배치 규칙 |
|---|---|---|
| 1 | 🗺️ **인터랙티브 지리 지도 (`geojson`/`topojson`)** | 좌표·경로·거점이 있으면 GitHub 라이브 `geojson` 코드 블록(마커 색 `marker-color`·경로선 `stroke` 포함, `[경도, 위도]` 순서)을 본문에 직접 삽입하고, 오프라인·인쇄용 `Leaflet` 정지 지도 또는 좌표표를 나란히 둔다. |
| 2 | 🏷️ **다중 줄 네온 SVG 배지 월 (`scripts/badge.py`)** | `H1` 제목 바로 아래에 `<div align="center">` 2~4행으로 릴리스·라이선스·CI·도구 수·호스트·핵심 엔진·핵심 수치를 클릭 가능한 2톤 직사각형 SVG 배지 월로 촘촘히 배치한다. [배지 생성기](scripts/badge.py)는 배경 휘도(WCAG)에 맞춰 `#ffffff`/`#000000` 글자색을 자동 선택한다. |
| 3 | ⚡ **고밀도 시맨틱 이모지 리듬** | 모든 절 제목(`H2`/`H3`), 설치 단계, 비교 표, 상태 목록, 프롬프트 레시피에 의미가 통일된 이모지를 적극 배치하고 항상 텍스트 레이블과 짝지운다(예: `✅ 완료`, `🔥 핵심`, `🔌 설치`, `🧪 검증`, `⚠️ 주의`). |
| 4 | 🎬 **루프 애니메이션 GIF + 정지 PNG (`<picture>`)** | 시간 변화·동작·파형·조명 큐·UI 전이를 `12~36`프레임 루프 GIF로 제작해 최상단 히어로와 핵심 절에 배치하고, `<source media="(prefers-reduced-motion: reduce)">`로 동일 해상도 정지 PNG를 짝지운다. |
| 5 | 🗂️ **열 정렬 역할 주석 디렉터리 트리** | 실제 저장소 경로만 `text` 코드 블록(`├──`, `│`, `└──`)으로 그리고 각 줄 오른쪽에 `← 역할 설명`을 동아시아 전각 폭 기준 단일 열로 칼같이 정렬한다. |
| 6 | 📣 **GitHub 알림 5종 전량 (`5/5`)** | 문서 전체에서 배경(`[ !NOTE ]`→`[!NOTE]`), 실전 요령(`[ !TIP ]`→`[!TIP]`), 필수 전제(`[ !IMPORTANT ]`→`[!IMPORTANT]`), 사전 오류 경고(`[ !WARNING ]`→`[!WARNING]`), 덮어쓰기·손실 위험(`[ !CAUTION ]`→`[!CAUTION]`)의 **5종 모두** 근거 있는 문단을 찾아 고루 배치하고 `사용한 유형 수/5`를 보고한다(근거가 전혀 없으면 날조하지 않고 생략 사유를 적는다). |

## 3단계 · 25종 도구 매트릭스

### 구조·신호·악보 (`9`종)

| 도구 | 최적 용도 & 고자극 연출 포인트 |
|---|---|
| **Mermaid** | 흐름·분기·상태·간트 — GitHub 네이티브 `classDef` 네온 테마 + 정적 카드 |
| **PlantUML** | 참여자별 요청·응답·프로토콜 시퀀스 — 고대비 다크 스킨파람 시퀀스 |

| **D2** | 계층·클러스터·인프라 랙·서비스 경계 — 중첩 컨테이너 + 글로우 연결선 |

## 4단계 · 게시 환경별 전달 전략

- **GitHub README / Docs:** 네이티브 `mermaid`·`geojson`·`$$...$$`·알림 5종·`<picture>` GIF·2톤 SVG 배지 월·`<details open>` 25종 갤러리 월을 모두 가동하고, 나머지 렌더러는 로컬 고해상도 PNG/SVG 상대 경로로 삽입한다. 모든 내부 앵커·경로·이미지 디코딩을 확인한다.
- **Obsidian:** 기본 Mermaid·네이티브 LaTeX·로컬 첨부 PNG/SVG를 우선 배치하고, 전용 플러그인 문법은 대상 볼트에서 활성화된 경우에만 쓴다.
- **네이버 블로그·인쇄·오프라인:** 첨부·복사가 깨지지 않도록 정적 PNG + 복사 가능한 원문 코드 + 읽을 수 있는 수식 텍스트를 함께 제공한다.
- **Quarto·Observable·웹앱:** 실행 엔진이 지원하는 인터랙티브 차트를 직접 구동해 초기화와 실데이터 렌더를 확인한다.
- **신뢰 경계:** 사내 원문·데이터의 렌더링은 로컬에서 처리한다. 문서 시각화 지시만으로 외부 호스팅이나 원격 게시는 수행하지 않는다.
